КОНТУР — запуск на Linux / VPS

Нужен Python 3.11+. Node.js для запуска не нужен.
В папке contour-python создай .env по образцу .env.example. Заполни
CHAT_PASSWORD для гостей и, по желанию, CHAT_ADMIN_PASSWORD для владельца.

  python -m pip install -r requirements.txt
  python main.py

Используй python3 вместо python, если так называется команда на хосте.
В панели хостинга можно указать main.py как файл запуска, а requirements.txt
как список зависимостей. Переменные хостинга имеют приоритет над .env.

Если CHAT_ADMIN_PASSWORD не задан, создаётся .data/admin-password. Используй
пароль владельца для «Настройки API»: введи HTTPS URL OpenAI-совместимого
API, ключ и название модели. Настройки общие, ключ не передаётся гостям.

По умолчанию приложение слушает только 127.0.0.1:8000. Для проверки с
компьютера подключись к VPS отдельной командой (замени USER своим логином):

  ssh -N -L 8080:127.0.0.1:8000 USER@94.156.131.235

Открой http://localhost:8080 в браузере. SSH-туннель шифрует трафик до VPS.

Чтобы дать доступ другим пользователям, привяжи домен к IP VPS и поставь
обратный прокси с HTTPS, например Caddy. Пример Caddyfile (замени домен):

  chat.example.com {
      reverse_proxy 127.0.0.1:8000
  }

Для такого прокси укажи TRUST_PROXY=1 в .env. Если панель сама завершает
HTTPS и требует внешний bind, используй HOST=0.0.0.0 и её PORT.
Не публикуй порт приложения по обычному HTTP: при вводе пароля или ключа
они не будут защищены на сетевом участке без TLS. HOST и PORT можно менять
через переменные окружения. Для постоянной работы запускай приложение как
службу от отдельного пользователя, а не из временной SSH-сессии. Храни
пароли и папку .data закрытыми; используй отдельный лимит расходов у API.
